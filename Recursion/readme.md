# 🔁 Recursion in Python

This folder contains my solutions and practice programs for learning **Recursion** in Python as part of my **Python DSA Journey**.

Recursion is a programming technique where a function calls itself to solve smaller instances of the same problem. It is widely used in Data Structures and Algorithms for solving problems involving trees, backtracking, divide and conquer, and dynamic programming.

- Base case and recursive case
- Call stack

- String recursion
