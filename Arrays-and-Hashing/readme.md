# Arrays and Hashing

This folder contains beginner DSA problems based on:
- Arrays
- Sets
- HashMaps
- Frequency Counting

- Valid Anagram
- Two Sum
- Majority Element
- Top K Frequent Elements
- Intersection of Two Arrays

## Concepts Learned
- HashMap usage
- Set operations
- Frequency counting
- Fast lookup
- Time complexity optimization
