# Inventory Management System

A simple Python-based Inventory Management System that allows users to manage items and their quantities using a menu-driven interface.

## Features

- Add Item
- Search Item
- Delete Item
- Display Inventory
- User-Friendly Menu System

## Technologies Used

- Python
- Dictionary Data Structure
- Functions
- Loops and Conditionals
