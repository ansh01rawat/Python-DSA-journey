# Menu-Driven Python Program

A beginner Python project that uses a menu-driven approach to perform different operations based on user input.

## Features
- Display menu options
- Take user input
- Perform selected operations
- Repeat until user exits program

## Concepts Used
- Functions
- Loops
- Conditional Statements
- User Input Handling
- Menu Logic

## Example Menu

1. Add  
2. Search  
3. Delete  
4. Display  
5. Exit  

## Goal

This project was built to practice:
- program flow control
- logical thinking
- function-based programming
- interactive console applications

## Language Used
Python
