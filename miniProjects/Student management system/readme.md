# 🎓 Student Management System

A command-line based Student Management System built using **Python** and **Object-Oriented Programming (OOP)**. This project allows users to efficiently manage student records through a menu-driven interface with persistent storage using file handling.

## 🚀 Features

- ➕ Add a new student
- 🔍 Search for a student
- ❌ Delete a student
- ✏️ Update student details
- 📋 Display all students
- 💾 Save student records to a file
- 📂 Automatically load saved records
- ⚠️ Input validation and exception handling
- 🏗️ Implemented using Object-Oriented Programming (OOP)

## 🛠️ Technologies Used

- Python
- Object-Oriented Programming (OOP)
- Dictionaries
- Functions
- File Handling
- Exception Handling
