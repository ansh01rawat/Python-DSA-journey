# 🌳 Trees in Python

This folder contains my implementations and practice programs for the **Tree** data structure as part of my **Python DSA Journey**.

A **Tree** is a non-linear hierarchical data structure consisting of nodes connected by edges. Unlike linear data structures such as arrays or linked lists, trees organize data in a parent-child relationship, making them ideal for representing hierarchical information like file systems, organization charts, and expression trees.

## 🌳 Binary Tree Traversals

### Inorder Traversal

```text
Left → Root → Right
```

### Preorder Traversal

```text
Root → Left → Right
```

### Postorder Traversal

```text
Left → Right → Root
```

---

## ⏱️ Time Complexity

| Traversal | Time | Space* |
| --------- | ---- | ------ |
| Inorder   | O(n) | O(h)   |
| Preorder  | O(n) | O(h)   |
| Postorder | O(n) | O(h)   |

*`h` = Height of the tree (recursive call stack).
