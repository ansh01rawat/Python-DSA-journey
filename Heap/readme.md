## 💡 Key Takeaways

* A heap is a **complete binary tree** represented using an array.
* Python's `heapq` module implements a **Min Heap**.
* A **Max Heap** can be simulated by storing negative values.
* Heap operations such as insertion and deletion take **O(log n)** time.
* Building a heap using `heapify()` takes **O(n)** time.
* Heaps are ideal for **Top-K**, **Priority Queue**, and repeated minimum/maximum element problems.
