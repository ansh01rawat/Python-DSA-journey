# 📥 Queue in Python

This folder contains my implementations and practice programs for the **Queue** data structure as part of my **Python DSA Journey**.

A **Queue** is a linear data structure that follows the **FIFO (First In, First Out)** principle, where the first element inserted is the first one to be removed. It is widely used in operating systems, scheduling algorithms, graph traversal, and buffering applications.
